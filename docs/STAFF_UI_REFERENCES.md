# Staff portal UI references

The redesign uses these projects as visual and interaction references:

- [ocr-cockpit](https://github.com/shuntakondo/ocr-cockpit) (MIT): document queue beside an evidence and extracted-data review area.
- [shadcndashboard](https://github.com/shadcndashboard/shadcndashboard) (MIT): navigation, summary cards and compact data views.
- [assistant-ui](https://github.com/assistant-ui/assistant-ui) (MIT): chat attachment presentation.

The React components and CSS in this project were written for the existing Q&M app. No source files, assets or component implementations from those repositories were copied, so no third-party code notice was added.
